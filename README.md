# Dice Roller

A simple kotlin appliciation that opens a window and allows the user to navigate a list of dice options that when selected generate a random value, like a set of dice would. This file was created during a two week long effort to teach myself the basics of the Kotlin programming language.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Ensure that you have the development environment set up as detailed in the Development Environment section.
2. Press play to run the program.

Instructions for using the software:

1. Run the program.
2. Navigate using the arrow keys to hilight the dice you want to roll.
3. Press enter to roll a highlighted die.
4. When finished rolling press "q" to quit.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Dowload the Oracle java development kit
* Download the Koltin Programming Language compiler
* Add the koltin compiler to your computers variable path
* Download IntelliJ Idea
* Enable the Kotlin, Kotlin multiplatform, and kotlin Notebook plugins.
* Create a new project with a gradle build system
* Add lanterna implamentation to the Gradle dependencies list in the build.gradle.kts file.
* Create a new file with a name ending in .kt within the kotlin folder.
